# AI 原图导出 v0.2.7

[English](README.en.md)

桌面 Chrome / Edge Manifest V3 扩展，最低 Chrome 116。本地读取平台已提供的原始图片，支持紧凑五列预览、选择、单张保存、批量逐张下载、ZIP 打包和设置帮助；不进行像素修复或重新生成。

## 安装与更新

1. 下载并解压 [最新 Release](https://github.com/fangxiaoxingit/WatermarkRemover/releases/latest)，或在本目录运行 `npm ci`、`npm run build`。
2. 打开 `chrome://extensions/`（Edge 为 `edge://extensions/`），启用开发者模式。
3. “加载未打包的扩展程序”选择 `dist/`。
4. 已安装的旧版本点击“重新加载”，然后刷新千问、豆包聊天页或分享页。
5. 点击聊天页或分享页右下角蓝紫色“导出原图”；设置与帮助也可从工具栏入口打开。

可分发包：`ai-original-export.zip`。解压后加载包含 `manifest.json` 的目录。

## 使用

- 设置页右上角可选择“跟随浏览器 / 简体中文 / English”。默认跟随浏览器界面语言，其他语言回退英文；中文区域语言统一使用简体中文。手动选择会保存在当前浏览器中，切换时保留图片选择、预览和运行中的下载任务。
- 首次打开面板默认选中已识别的图片；后续新增图片不自动加入选择，关闭重开保持选择。
- 桌面端每行 5 张，约 116×155 像素、3:4 竖图预览；窄屏自动改为 2 列。
- 每张缩略图右下角可点击放大图标，在当前页面按原图比例预览；点击关闭、背景空白或按 Esc 返回，不影响已选图片。
- 点击单张下载、逐张下载或 ZIP 后，不会打开新页面。全选按钮上方显示获取、打包、浏览器保存和完成进度。
- 关闭面板或切换页面后导出仍继续；返回原聊天可查看状态。不要在下载中重载扩展或退出浏览器。
- “逐张下载”位于 ZIP 按钮左侧，按选择顺序保存为独立图片文件。逐张任务取消或失败后，重试仅下载未保存图片，并保留原来的文件编号。
- 支持取消、失败重试；部分 ZIP 保存成功后可仅重试失败项。若浏览器保存失败，重试整批未保存图片。
- 每批最多 100 张或 200 MB，保存到默认下载目录下的 `原图导出`（中文）或 `Original Images`（英文），同名文件不会覆盖。文件命名和 ZIP 内的失败说明使用任务开始时的语言，切换界面语言后仍保持一致。
- 支持千问聊天页、分享页，以及豆包聊天页和 `/thread/` 分享页。豆包仅收录当前渲染的生成图片，向上滚动会增量识别历史内容。
- 平台原图本身可能仍有可见水印。扩展提取原始资源，不保证修复这类水印。

## 开发与验证

- `npm test`：解析、边界、下载、取消和重试测试。
- `npm run build`：TypeScript 严格检查和扩展构建。
- `npm run test:browser`：独立 Chromium 正式扩展集成测试。首次需 `npx playwright install chromium`。
- `node scripts/icons.mjs`：从 `icons/source.svg` 渲染 16 / 32 / 48 / 128 px 图标。
- `npm run format`：格式化源码。

`src/adapters.ts` 解析资源，`src/bridge.ts` 只读获取页面数据，`src/content.ts` 展示面板与进度；`src/background.ts` 校验任务、维护进度并调用浏览器下载；`src/offscreen.ts` 在隐藏文档获取、验证和打包原图。后台只使用 runtime 消息与隐藏文档通信，Blob 不传到宿主网页。

图标为主题色 `#4D55CC` 实心橡皮擦与清除标记，透明背景；工具栏与管理页使用 PNG，页面内图标使用同源 SVG。

自动化浏览器测试使用虚构结构和合成图片，不能替代真实平台的新版本验收。
